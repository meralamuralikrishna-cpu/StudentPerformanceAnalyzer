# Student Performance Analytics

A simple Python project that analyzes student scores using **NumPy** and visualizes results with **Matplotlib**.

## Features

* Generate random student scores
* Assign grades automatically
* Calculate statistics (Mean, Median, Variance, Standard Deviation, Percentile)
* Find top and bottom performers
* Calculate pass percentage
* Generate grade distribution
* Visualize grade distribution and score histogram
* Store results in JSON

## Technologies

* Python
* NumPy
* Matplotlib
* JSON

## Run

```bash
python main.py
```
